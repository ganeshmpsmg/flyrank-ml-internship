## Part 4 — "Where It Breaks" (Ready for Portal / Checkpoint 2 Submission)

### Where It Breaks (Honest Stress-Test & Failure Boundaries)
1. **Static Hosting Contact Form Boundary (`KNOWN LIMITATION`):**
   - Because the site is hosted as a zero-cost static deployment on GitHub Pages (`docs/index.html`), there is no server-side SMTP or database backend to silently store form submissions.
   - **How We Handled It:** Empty submissions (`Test #1`) and garbage/malformed inputs (`Test #2`) are blocked client-side with `aria-invalid="true"` and field-specific alerts. Rapid 5x clicking (`Test #3`) is intercepted by a synchronous 5-second cooldown lock (`data-submit-count="1"`, `data-blocked-clicks="4"`). Validated submissions generate a pre-filled GitHub Issue link and direct LinkedIn outreach link rather than silently failing.
2. **Dense Academic Data Tables on Narrow Mobile Screens (`375px` Width) (`KNOWN LIMITATION`):**
   - While the document body itself has `0px` horizontal overflow across Mobile (`375×667`), Tablet (`768×1024`), and Desktop (`1280×800`), Section 11's 11-column model evaluation table (`798px` wide) and Section 14's Top-10 recommendation queues contain too many numeric metrics to stack vertically without destroying side-by-side comparability across splits.
   - **How We Handled It:** Wrapped all tables in `.table-wrap` containers with `overflow-x: auto; -webkit-overflow-scrolling: touch;` so mobile readers can swipe horizontally inside the bordered card while the rest of the page remains locked to the viewport width.
3. **Cold-Cache SVG Payload on Throttled Slow-3G Connections (`KNOWN LIMITATION`):**
   - To keep the research paper self-contained with crisp vector typography, all 5 figures (`fig1`–`fig5`) are embedded as standalone SVGs (`675 KB` combined; `fig3_logistic_regression_coefficients.svg` is `317 KB` due to vector text paths).
   - **How We Handled It:** Added explicit intrinsic `width` and `height` attributes to all 5 `<img>` elements (preventing Cumulative Layout Shift while loading), set `fetchpriority="high"` on Figure 1, and enabled native `loading="lazy" decoding="async"` on Figures 2–5 so below-the-fold figures do not compete with initial HTML/CSS rendering.
4. **Model & Data Boundary (From Section 15 of the Approved ML Capstone):**
   - Our 7-feature pre-decision Logistic Regression model (`Accuracy = 0.6688`, `ROC AUC = 0.7144`, `Precision@50 = 0.6200` on unseen held-out clients) is strictly an **observational decision-support triage tool**, not a causal predictor. It can produce false positives on zero-click SERP layouts (e.g., `content_3e79eaafc89d`) or newly surging pages (`content_8fdbff16a886`) when 30-day sub-window features are withheld to prevent target leakage.
